# PS Spinz

Three new DJ tracks a day. Keep them (they go into the crate, and into the "PS Spinz" Spotify playlist) or drop them. Every keep and drop teaches the daily picker, a scheduled Claude run that follows `PICKER.md`.

Live at https://abratica.github.io/ps-spinz/. Open it in Safari and use Share → Add to Home Screen.

- `data/spinz.json`: the crate, the inbox and the keep/drop history. The app saves to it through the GitHub API.
- Settings in the app (gear icon): a GitHub fine-grained key with Contents read/write on this repo, and a Spotify Client ID.
